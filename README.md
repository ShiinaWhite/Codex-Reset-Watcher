# Codex Reset Watcher（Codex 额度重置提醒）

这是一个 MaiBot 插件，自动盯守 OpenAI Codex 的额度重置动态，并把提醒发到你指定的 QQ 群里。

- 当前版本：**0.1.12**
- 运行环境：MaiBot（Host 1.0.0 – 1.2.99，SDK 2.8.0 – 2.99.99，以插件清单声明为准）
- 许可证：MIT

## 它是做什么的

插件定期查询公开的 Codex 重置信息网站，发现值得注意的动态时在群里发一条通知。它不登录你的 OpenAI 账号，也不触碰你的额度，只读取公开数据：

| 它盯什么 | 你会收到什么提醒 |
| --- | --- |
| Codex 全局额度重置 | 官方宣布的全局重置消息，以及随后确认生效的消息 |
| Banked Reset（存入额度） | 上游推送给用户的 Banked 动态（含生命周期状态暂时不明确的事件，以数据源的用户推送决策为准）；存入账户后由你手动兑换 |
| 重置告警 | 数据源转发给用户的重置预警，同一件事只提醒一次 |

每条完整提醒都是同一套结构：**中文翻译**（AI 完整翻译）→ **Tibo 原文**（完整原文或摘录）→ **原帖链接**。翻译由大模型生成，原文说什么就翻什么（包括歌词、玩笑），能可靠确定的时间会换算成北京时间自然融入译文。

## Banked Reset 是什么

Banked Reset **不是额度立刻刷新**，而是把「一次重置机会」存进你的账户，什么时候用由你自己决定。收到 Banked 提醒，意思是「你账户里多了一次可用的重置机会」；具体的兑换操作仍需你在 OpenAI 侧手动进行。

## 0.1.12 带来的变化

0.1.11 存在一个已证实的漏报：当数据源把一次 Banked Reset 推送给了用户、但该事件在结构化数据里的生命周期状态暂时是 `unknown` 时，插件会在提取阶段把它静默（2026-09-09 的真实事故：数据源已推送、Telegram 已发送，QQ 没有任何提醒。完整取证见 [evidence/v0.1.12/](evidence/v0.1.12/)）。

0.1.12 新增「上游推送镜像」：插件同时读取数据源面向用户的推送通知内容（与其浏览器推送同源）。当插件在轮询时观察到上游已经决定向用户推送一条 Banked 告警，就将该告警镜像到 QQ——标题、原文翻译、原帖结构与其它提醒完全一致。触发只看上游已经做出的推送决策，插件不做第二层语义判断，也不会因为状态是 `unknown` 就静默。

**已知限制（诚实说明）**：这个推送面是"最新一条"性质，上游不提供历史记录。如果插件停机或两次检查之间，上游恰好推送了某条 Banked 消息、随后又被更新的消息覆盖，这条消息将无法找回。0.1.12 覆盖检查时仍然可见的上游 Banked 推送，不承诺离线恢复或被覆盖后的补偿；离线期间的补偿需要数据源提供带历史/游标的告警接口，属于上游能力范围。

## 安装

1. 下载或克隆本仓库；
2. 把 `codex_reset_watcher/` 文件夹放进 MaiBot 的插件目录，由插件加载器加载；
3. 在 MaiBot WebUI 中打开本插件的配置页，把要提醒的群号填入 `group_ids`。

不需要申请 OpenAI API key，也不需要 X（Twitter）API key。

## 配置群与常用选项

配置都在 WebUI 里完成，不需要手动编辑文件。常用项如下：

```toml
[watcher]
group_ids = []            # 要提醒的群号列表，例如 ["100000001"]
check_interval = 240      # 每隔多少秒检查一次，默认 240（4 分钟）
timezone = "Asia/Shanghai"

[llm]
enabled = true            # 中文翻译开关
model_task = "replyer"    # 模型任务：WebUI 提供 replyer / planner / utils 推荐单选
```

完整默认值见 [config.toml](codex_reset_watcher/config.toml)。

### 多群支持

`group_ids` 里可以填任意多个群。每个群独立发送、独立去重、独立重试：一个群发送失败不影响其他群，同一条提醒也不会在同一群里重复出现。

## 中文翻译是什么

开启后，插件会让 MaiBot 自带的大模型把通知原文**完整、忠实地**翻译成简体中文（不摘要、不删减），并按推文发布时间把能可靠确定的时间表达换算成北京时间。

- 翻译只是让通知更好读，**失败或超时会自动降级为无翻译的普通通知**，不影响提醒本身；
- 它复用 MaiBot 已有的模型任务（默认 `replyer`），**不需要单独的 OpenAI 或 X API key**；
- 不想用的话，在 WebUI 里把 `llm.enabled` 关掉即可。

## 常见问题

**同一件事会重复提醒吗？**
每个群都有独立的通知记录，同一条告警、同一次确认在一个群里只发一次。

**为什么提醒时间是北京时间？**
通知中的时间按北京时间（Asia/Shanghai）理解与展示。

**重启后会漏提醒或重复播报吗？**
插件把已发送的通知记录保存在 MaiBot 数据目录的 `reset_state.json` 里，重启后继续按记录去重，不会把老消息重新播一遍；某次发送失败会按群重试。

**通知太频繁怎么办？**
调大 `check_interval`（单位：秒）可以降低检查频率。没有新事件时插件不会发任何消息。

**翻译不准？**
翻译由大模型生成，仅供参考，通知中保留能够获取到的 Tibo 原文或原文摘录，可自行核对；翻译失败时自动降级为无翻译的普通通知。无法获取到推文原文时，提醒只包含标题与原帖链接，不会用摘要冒充原文。

**从旧版本升级会丢配置吗？**
不会。旧的单群配置（`group_id`）会自动迁移到多群列表 `group_ids`，无需手动处理。
